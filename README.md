# 🧠 思维模型 108 - 互动学习工具

一个基于 Vue 3 + Vite 的 H5 互动式思维模型学习应用。

## 🚀 快速开始

### 安装依赖
已安装，直接运行：

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## ✨ 功能特性

- 📱 **移动端优先设计** - 完美适配手机和平板
- 🎯 **108 个思维模型** - 包含认知、决策、组织、创新等模块
- 📊 **学习进度追踪** - 实时显示学习进度
- ⭐ **收藏功能** - 收藏喜欢的模型随时复习
- 📝 **互动测试** - 每个模型配有测试题巩固知识
- 🎨 **精美 UI 设计** - 渐变色、卡片式布局

## 🛠️ 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Vue Router** - 官方路由管理器
- **Pinia** - Vue 官方状态管理库
- **Vant UI** - 轻量、可定制的移动端组件库

## 📱 页面介绍

1. **首页** - 展示所有思维模型卡片，支持搜索和分类
2. **模型详情页** - 模型详情、标记已学、收藏
3. **测试页** - 互动测试巩固知识
4. **个人中心** - 学习统计、收藏夹
